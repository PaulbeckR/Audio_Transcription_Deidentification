# Prepared Datasets Directory

This directory stores preprocessed datasets in HuggingFace Arrow format.

## Structure

```
prepared_datasets/
├── whisper_finetuning/
│   ├── train/               # Training split (gitignored)
│   ├── validation/          # Validation split (gitignored)
│   └── dataset_dict.json    # Dataset metadata
├── whisper_finetuning_simple/
└── .gitkeep
```

## Important Notes

- **Arrow files (.arrow) are NOT tracked in git** - They are very large (100MB+)
- Only README files and .gitkeep are version controlled
- Datasets are generated by running `src/data/prepare_hf_dataset.py`
- Configuration is in `config/paths.yaml`

## File Types (Not in Git)

- `*.arrow` - HuggingFace Arrow format data files (large)
- `*.parquet` - Parquet format data files
- Dataset cache files

## Generating Datasets

To create prepared datasets:

```bash
# Basic preparation
python src/data/prepare_hf_dataset.py

# With configuration
python src/scripts/run_training.py --prepare-only
```

The preparation script will:
1. Load raw training data from `training_data/`
2. Tokenize and preprocess
3. Save to this directory in Arrow format
4. Generate metadata JSON files

## Metadata Files

Small metadata files (JSON) are tracked in git:
- `dataset_dict.json` - Dataset splits and structure
- `dataset_info.json` - Dataset statistics
- `state.json` - Processing state
